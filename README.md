# NYC Taxi Trip Data Analysis

## Project Overview
Exploratory Data Analysis and Multivariate Visualization
of NYC Taxi Trip Data using Python.

## Objectives
- Clean and preprocess taxi trip data
- Perform statistical and univariate analysis
- Visualize data using Matplotlib, Seaborn, Plotly and Bokeh
- Analyze correlations and relationships
- Apply PCA for dimensionality reduction
- Build a machine learning classification model

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Plotly and Bokeh
- Scikit-learn
- Google Colab

## Dataset
NYC Yellow Taxi Trip Data from Kaggle.
The dataset is not included in this repository because
the raw data files can be very large.

## How to Run
1. Open the notebook in Google Colab.
2. Download the dataset from Kaggle.
3. Upload the CSV in Colab.
4. Run the notebook cells in order.
